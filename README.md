# OwnPlay Mobile

OwnPlay Mobile is being rebuilt from zero as a Mobile-only Android media player and playlist organizer.

- Application ID: `app.ownplay.mobile`
- Primary navigation: Live / Library / Settings
- UI direction: dark, cinematic, media-first OwnPlay design based on the approved project references
- Engineering lane: source-only / NO APK unless QA packaging is explicitly authorized

The previous Mobile implementation remains available through Git history only and is not the active rebuild architecture.
